Dette tar vi hånd om

Aldri sårbar ved sykdom eller ferie

Bruk oss som ferievakt. Når medlemsansvarlig har ferie eller er borte, sørger vi for at kontingenten kreves inn og at medlemsservicen holdes oppe.

Dere slipper daglig fakturering. Vi håndterer e-posthenvendelser og purringer fra medlemmene.

Vanlige spørsmål om Medlem123

Hva koster Medlem123?

Oppstart koster kr 2 500, som dekker oppsett av systemet, import av medlemsdata og opplæring. Deretter betaler foreningen kr 299 per måned pluss kr 2 per medlem per måned. Kontingentinnkreving koster kr 10 per krav og purring kr 10 per purring, begge pluss betalingsservicegebyr. Din side er valgfritt og koster kr 99 per måned. Alle priser er eks. mva.

Hva gjør Klopp AS, og hva gjør foreningen selv?

Klopp AS håndterer alt som gjelder medlemmene: medlemsregisteret, kontingentkrav, purringer og spørsmål om medlemskap og betaling. Foreningen håndterer fortsatt alt som gjelder organisasjonen selv, og beholder full oversikt over egne medlemmer.

Hva er forskjellen på Medlem123 og Regweb?

Det er samme medlemssystem. Med Regweb driver foreningen systemet selv. Med Medlem123 drifter Klopp AS systemet for dere og tar det daglige arbeidet med kontingentinnkreving og medlemsservice.

Kan medlemmene melde seg inn og betale med Vipps?

Ja. Abonnementet inkluderer nettinnmelding på foreningens nettside, med betaling via Vipps eller kort.

Hvor lagres medlemsdataene?

All utvikling, drift og support skjer hos Klopp AS i Norge, og alle data lagres på norske servere.

Hvordan kommer vi i gang?

Ring 33 31 28 00 eller send oss en melding via kontaktskjemaet. Så avtaler vi oppstart, import av eksisterende medlemsdata og opplæring.

Usikker på om foreningen bør gjøre jobben selv eller la oss ta den?

Ring oss på 33 31 28 00 for en gratis og uforpliktende prat, så finner vi den beste løsningen sammen.

Usikker på om dere vil gjøre jobben selv?

Ring oss på 33 31 28 00 for en gratis og uforpliktende prat. Vil foreningen heller drive medlemsregisteret selv, se Regweb.
