Regweb / Funksjoner

Funksjoner

Medlemsregister, betaling og kommunikasjon i én løsning.

Regweb dekker alt en forening trenger for å drive medlemsarbeidet: register, betaling, kommunikasjon og tilgangsstyring. Dette er funksjonene dere får.

Medlemsregisteret

Medlemseditor

Her behandler dere alle medlemmer i organisasjonen. Legg inn et nytt medlem på sekunder, med automatisk sjekk for doble medlemmer.

Telefonkatalog-oppslag

Søk direkte i telefonkatalogen og hent inn eller oppdater opplysninger. Alt som trengs for å legge inn et nytt medlem er telefonnummer eller navn.

Søk og filter

Filter er et avansert søkeverktøy som søker i all informasjon. Kombiner det med søkemerker og etiketter for å finne grupper.

Valgfrie felt og tabeller

Foreningen bygger selv egne tekstfelt, datofelt, tabellfelt og ja/nei-felt. Feltene kan brukes i søk, rapporter, eksport og nettinnmelding.

Dokumenter og notater

Hvert medlem kan ha ubegrenset antall dokumenter, bilder og notater. Notater kan deles inn i egne kategorier.

Aktiviteter

Hold orden på hvem som deltar på kurs, møter og konferanser. Aktivitetsmodulen har også nettpåmelding fra foreningens nettside.

Historikk over endringer

Loggen viser alle endringer som er gjort på et medlem, og kan skrives ut som rapport.

Betaling og økonomi

Kontingent

Medlemstypene bestemmer kontingentsatsene. Kontingent og produkter behandles på samme måte, som gjør systemet svært fleksibelt.

Fakturering og purring

Send faktura og purring på e-post med PDF-vedlegg. Ubegrenset utsendelse er inkludert i serviceavtalen.

Betalingsmetoder

Bankkort, Vipps, eFaktura, Avtalegiro og SMS-betaling. OCR-giro-modulen leser inn filer fra banken, og medlemmene settes til betalt automatisk. Avtalegiro, eFaktura og SMS har egne priser.

Betal for andre

En forelder kan betale for barn eller andre familiemedlemmer. Foreningen sender én faktura for alle, og kan holde oversikt over hvem som er i slekt.

Produkter

Legg inn produkter foreningen selger, og send enkelt faktura til kunder og medlemmer.

Rapporter uten regnskapserfaring

Hent ut revisorrapporter og lister selv, og send dem til regnskapsfører.

Kommunikasjon

Nyhetsbrev på e-post

Send nyhetsbrev til ett eller flere medlemmer. Brevene kan gjøres personlige med navn og andre opplysninger.

SMS fra medlemseditoren

Send SMS rett fra medlemseditoren. SMS er en egen modul med egne priser, også for distriktsavdelinger.

Chat-modul

Medlemmene logger inn på Din side og starter en samtale når de vil, i ulike tråder.

AI-assistent

En AI-assistent på Din side kan svare på medlemmenes spørsmål om innmelding, medlemsfordeler, arrangementer og praktiske rutiner, slik foreningen ønsker det.

Medlemmene selv

Nettinnmelding

Innmeldingsskjemaet kobles til foreningens eksisterende nettside. En egen designer gjør at foreningen selv kan tilpasse skjemaet. Nye medlemmer betaler med Vipps eller kort, og registreres automatisk som betalt.

Din side

Medlemmene oppdaterer selv personalia og logger inn med Vipps. Via API velges hvilke felt og faner som vises.

Donasjoner

Motta små og store bidrag fra medlemmene via Din side, med Vipps eller kort.

Bladmodul og dokumentmodul

Medlemsblad online og nedlastbart, og et arkiv for årsberetning, regnskap og referater. Begge er valgfrie moduler med egne priser.

Organisasjon og tilgang

Distriktsavdelinger

Hver avdeling logger inn og håndterer «sine» medlemmer lokalt. Foreningseditoren behandler underorganisasjoner, og med samlefaktura kan dere sende faktura, purring og kreditnota til hver underforening.

Brukerroller

Flere tilgangsnivåer: sentralt ledd, distrikt og lokallag har tilgang til «sine» medlemmer, og hvert medlem har tilgang til Din side.

Teknikk og sikkerhet

Full API

Koble Regweb sammen med eksisterende nettside og andre systemer. Regweb er 100 % integrert med XReg.

Regweb Framework

Moduler kan tilpasses hver organisasjon. Klopp AS utvikler den tilleggsfunksjonaliteten dere trenger.

Sikkerhetskopi

Automatisk backup, pluss mulighet for manuell sikkerhetskopi og gjenoppretting.

Personvern (GDPR) og norske servere

Innebygd personvern, og alle servere står i Norge. Klopp AS er databehandler for foreningens medlemsdata.

Skybasert tjeneste

Ingen lokal installasjon. Drift og backup utføres av Klopp AS på moderne, sikre servere.
